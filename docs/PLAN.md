> 设计稿。最初目标为「训练家 → 主宠 → 爬塔 → 宝箱 → 词条 → Boss」的单局闭环；
> 当前实现已扩展为 40 层、4 名旧首领加 4 代魔王、必出宝箱、英雄精灵、元素共鸣与层间奇遇。
> 若文档与实现不一致，以 README 与 `data/content.json` 为准。

| 定位 | 核心玩法验证 | 内容与养成验证 |
|---|---|---|
| 精灵数量 | 50 只可随等级进化的原创精灵 |
| 上阵 | 5 上阵，仓库不限 |
| 爬塔 | 40 层，4 个世代。旧首领在第 5 / 15 / 25 / 35 层，魔王在第 10 / 20 / 30 / 40 层 |
| 小怪来源 | 从当前层精灵池按等级、属性、职业、阵型算法生成；逐层变强并携带词条 |
| Boss 素材 | 原创首领立绘 + 随机增益 + 多阶段觉醒 + 阶段护盾 |
| 战后奖励 | 精灵 / 道具 / 词条必出；精灵稀有度 45/25/15/10/5，英雄只是 5% 档 |
| 技能成长 | 词条三选一：选精灵 + 选技能 + 附着；每技能 3 条、每精灵 6 条 |
| 阵型 | 九宫格自由摆放 5 只；站位只影响目标选择，不改变伤害 |
| 数据方式 | XLSX 可编辑表 + `content.json` 导入管线 |
| 主要目的 | 跑通战斗/爬塔闭环 | 跑通完整单局，并保证确定性种子可复盘 |

补充设定：玩家每通过一层全员 +5 级（上限 120）。每只精灵普攻或受击增加气势，2 点气势释放大招。

### 开局

- 训练家三选一：新手、高级、老练；Buff 全部来自 `Trainers` 表。选中的主宠不封顶。
- 三主宠为火 / 水 / 草；未选的两只仍可从宝箱获得。
- 初始只有 1 只主宠；通过宝箱扩充队伍，最多上阵 5 只。

### 普通层敌人

- 每层从 `Floors` 表指定的精灵池生成敌人：前四层依次 1 / 2 / 3 / 4 只，之后 5 只。
- 第 5 层起小怪逐层变强：属性倍率随层数上升，并周期性获得 1–2 条技能词条。
- 精英试炼（由层间奇遇触发）会让下一层敌人全属性 ×1.25，并额外掉落道具。

### Boss

- 小 Boss：第 5 / 10 / 15 层；大 Boss：第 20 层。
- 小 Boss 随机 2 条增益；大 Boss 随机 3 条。
- Boss 战带 4 只随从，随从从当前层精灵池生成。
- 所有 Boss 都在血量阈值进入新阶段：回满气势、获得护盾并叠加增益。
- 新增强增益：破防（无视 30% 防御）、狂怒（随已损生命提升伤害）、虹吸（吸血 + 回复）。

### 宝箱

每层胜利后独立判定，可同时获得：

| 奖励 | 概率 | 内容 |
|---|---:|---|
| 精灵 | 100% | 按稀有度权重抽取未拥有精灵，抽空则降档；重复转共鸣。不出首领与魔人 |
| 随机道具 | 100% | 按稀有度权重抽取；已达堆叠上限的道具不再出现 |
| 技能词条 | 100% | 3 个候选词条选 1，再选精灵和技能附着 |

- 战意项链最多持有 2 个；道具上限由 `Items.max_stack` 控制。
- 每技能最多 3 条词条，每精灵最多 6 条；满上限时替换已有词条或转随机道具。
- 词条三档：普通/稀有/史诗，默认权重 60/30/10。

### 元素共鸣

- 上阵同元素 2 只激活一阶、3 只激活二阶团队加成（生命 / 攻击 / 防御 / 速度 / 暴击）。
- 各元素加成写在 `Resonance` 表，可与精灵自身共鸣叠加。

### 层间奇遇

- 第 2 / 5 / 8 / 11 / 14 / 17 层通关后，从奇遇池抽 3 个选项：
  星辉宝库、远古遗物、四类永久祝福、共鸣之泉、远古契约、试炼之门、献祭祭坛、英雄熔炉。
- 第 5 层起必有「深渊契约」：献祭 1 件道具，获得一只未拥有的魔人。
- 可三选一，也可跳过；效果立即生效。

### 英雄精灵

- 与首领相同的元素特效与阶段觉醒，但使用 60% 强度的增益与更低的属性倍率。
- 拥有独立星级 0–3，每星全属性 +6%；升星消耗 1 件道具。
- 不与普通同种精灵共享共鸣，可重复获得。

### 阵型与地图

- 九宫格 3×3；靠近敌方为前排，中间为中排，最后为后排。
- 敌方坦克和战士优先前排。存活坦克嘲讽单体；同排坦克守护身后 30% 伤害。相邻职业有连携。
- 每层切换地图；Boss 层使用对应主题地图，地图只影响氛围。

## V2 可编辑表

- `Trainers` / `Starters`：训练家 Buff 与三主宠。
- `Pets_50` / `Skills`：属性、职业、数值、技能引用。
- `Affixes` / `Items`：词条与道具（含 `max_stack`）。
- `Bosses` / `Boss_Buffs`：首领倍率、增益池、阶段。
- `Floors`：层数、敌人数、等级、精灵池、随从倍率、敌方词条数。
- `Resonance`：元素共鸣阈值与团队加成。
- `Formation` / `Combat` / `Import_Report`：阵型、战斗常数、导入校验。

## 验收标准

- 代码和数据中不存在 `mirror` 或 `highestStat` 小怪规则；普通层只走 `floorPool` 生成。
- 20 层可通关；第 5 / 10 / 15 层小 Boss，第 20 层大 Boss。
- 3 训练家、3 主宠（火/水/草）、50 精灵、20 道具、4 首领、4 魔人、17 系共鸣。
- 精灵 / 道具 / 词条必出；英雄种约占精灵抽取的 5%，没有独立英雄卡。道具上限可生效。
- 英雄精灵可升星；层间奇遇与精英试炼可触发。
- XLSX 改表后能重新导入 `content.json`，无悬空引用。

## 默认假设

- 普通敌人从 50 只精灵池按属性/职业权重生成。
- 精灵缺少素材时使用程序化立绘，占位不阻塞导入。
- 后排是「造成伤害 -15%」的旧规则已废弃，现只影响目标选择。
